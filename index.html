Stopping a Ping Flood on a Physical SDN

  • Turned a Raspberry Pi 3 into an OpenFlow switch: flashed a Raspbian image with Open vSwitch, created the bridge, added the USB-to-Ethernet ports and pointed it at a Floodlight controller.
  • Used Postman as the SDN application, calling Floodlight's REST API to list every device the controller tracked and to read per-port RX/TX bandwidth before and during a ping flood.
  • Treated the ping flood as an attack and blocked only the attacker's ICMP traffic by pushing an ACL deny rule through the API. The hosts went from steady replies to "Request timed out", and clearing the ACL restored traffic.
Raspberry Pi 3 Open vSwitch Floodlight Postman REST API ACL

Information Engineering 3 Final · The Last Campaign · CPE 3353 · 2026

smart_toy AI Security Automation · Team Project

Intelligent Security Management using SDN

  • Built a closed-loop system that detects and blocks denial-of-service floods on a physical SDN: a Raspberry Pi 3 running Open vSwitch, controlled by Floodlight over a separate out-of-band management link.
  • Mirrored traffic to a Scapy packet sniffer that turns each 3-second window into a 6-feature vector (packet rate, byte rate, ICMP/TCP/UDP/ARP ratios) for a linear SVM classifier.
  • When an attacker is flagged, the AI agent calls Floodlight's REST API to push per-IP drop rules, re-applies them if they are cleared mid-attack, and handles multiple simultaneous attackers.
  • Tested against ICMP ping floods, TCP SYN floods, zero-payload UDP floods, ARP storms and giant-payload floods, with attacker roles rotated across hosts.
SDN Floodlight Open vSwitch Python · Scapy SVM Postman
fact_check Formal Verification · Team Project

Verifying a Three-Party Authentication Protocol

  • Modeled a sensor node / mobile node / server protocol (password-keyed hashes, elliptic-curve Diffie–Hellman shares, digital signatures) in Scyther's SPDL language.
  • Verified 25 security claims against a Dolev–Yao attacker: the sensor node and server passed every claim, but the mobile node failed 8 of its 9.
  • Traced the flaw through Scyther's attack graphs: the sensor node is never authenticated to the mobile node, so an intruder can swap in its own key share and control both session keys.
Scyther SPDL ECDH Protocol Analysis
